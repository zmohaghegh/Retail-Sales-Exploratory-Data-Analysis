# Retail Sales Exploratory Data Analysis (EDA)

This repository contains a comprehensive Exploratory Data Analysis (EDA) on retail sales data. The goal is to transform raw transactional data into actionable business insights using Python's data science ecosystem.

## 📊 Business Questions Addressed
- Which product categories generate the highest revenue?
- Which geographical regions are the most profitable?
- What is the distribution of transaction amounts?
- How does the sales trend behave over time (Monthly Analysis)?

## 🛠️ Technical Stack
- **Language:** Python
- **Libraries:** - `Pandas` for data manipulation and cleaning.
  - `Matplotlib` & `Seaborn` for advanced data visualization.
  - `NumPy` for numerical processing.

## 🚀 Key Features
- **Data Cleaning:** Handling missing values and ensuring correct data types.
- **Statistical Summary:** Detailed overview of sales distributions and averages.
- **Visual Insights:**
  - Bar Charts for Category and Regional performance.
  - Histograms with KDE for transaction density.
  - Time-series Line Plots for monthly revenue trends.
  - Correlation Heatmaps to find relationships between variables.

## 📈 Key Insights from the Analysis
- **Top Category:** Groceries (Highest total revenue).
- **Leading Region:** North (Most profitable area).
- **Average Ticket Size:** ~$254.88 per transaction.

## 📂 How to Use
1. Clone this repository.
2. Open `Retail_Sales_EDA_Analysis.ipynb` in Google Colab or Jupyter Notebook.
3. Run all cells to regenerate the analysis and plots.
